# Hub changelog - what is new (plain language)

Newest first. Written for players and server owners; no code details.

## 2026-09-27
- **Two download options** on the 12.1 release: the MidnightCore Launcher and the
  optional MidnightBotAI server module (bots). Pick one or both.
- **Super quick start**: every download now includes a simple step-by-step
  (QUICK-START.txt) with a short test checklist - extract, run, press PLAY.
- **Support**: issues are open - the README, the release notes and both downloads now
  point to where to report problems (with instructions on what to include).
- **MidnightBotAI 4.8**: tanks open fights and taunt; damage dealers hold fire until the
  tank has threat. Also includes level sync with the player, automatic gear upgrades,
  automatic talents, personal spacing, line-of-sight recovery, caster kiting, healer
  tank priority, group loot rules, combat chat and an in-game damage/healing meter.
- **Launcher cold start**: the launcher now waits (up to five minutes) until the world
  service is ready before opening the game, so you no longer land on a dead realm list.

## 2026-09-25
- **Launcher 0.1.0 published**: all-in-one start (starts the database and both servers),
  cold-start timer, menu music, bot status card, stop-servers button.
- **MidnightBotAI project added** to the hub with a plain-language changelog and source.

## Earlier (September)
- Hub guides for Vanilla / TBC / WotLK / Legion clients, server setup, data files,
  checksums, placement sheets, GM/SOAP notes and the LegionBotAI playerbot system.
