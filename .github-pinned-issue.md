Welcome! Start here, whatever brought you in.

**1) PLAYING ON WOW 12.1 (MidnightCore)**
- Download the **Launcher** zip from the release page:
  https://github.com/psychochaingang/LrdPsychoChains-WOW-HUB/releases/tag/launcher-v0.1.0-preview
- Extract it (do not run from inside the zip), run `LrdPsychoChains MidnightCore Launcher.exe`.
- First time only: point Settings at your game client folder. Then press **PLAY** - the
  launcher starts your servers, waits until the world is ready, patches the client and
  opens the game.
- Full steps + a quick test checklist: `QUICK-START.txt` inside the zip, and
  [docs/10-launcher.md](https://github.com/psychochaingang/LrdPsychoChains-WOW-HUB/blob/main/docs/10-launcher.md).

**2) OPTIONAL AI PARTY (bots)**
- Download the **MidnightBotAI server module** pack from the same release page and follow
  its README (it is a server add-on, not part of the launcher).
- In game, as the bot owner: `.mb pa` -> `.mb boostall` -> `.mb a` -> `.mb f`.

**3) RETURNING USERS**
- What changed recently is always listed here:
  [CHANGELOG.md](https://github.com/psychochaingang/LrdPsychoChains-WOW-HUB/blob/main/CHANGELOG.md).

**4) FOUND A BUG OR NEED HELP?**
Reply to this issue (or open a new one). Please include:
- what you did
- what you expected
- what actually happened
- the last lines from your launcher log and/or your world server log

We answer here - this is the official place for support, bug reports and requests.
